HDR Environment Map to Asset Tool

This tool converts .hdr and .exr environment maps into the .zasset asset format, making them easy to manage and use in the material library.

1. Tool Overview

The HDR Environment Map to Asset Tool can:

  • Convert single or multiple HDR/EXR files into .zasset assets
  • Recursively scan folders for environment maps
  • Automatically generate tone-mapped thumbnail previews
  • Preserve the original folder hierarchy
  • Import the converted assets directly into the current library category

2.3 Output Location

Choose the output folder for the assets. If none is specified, the tool automatically uses the directory of the input file as the output directory.

3. Workflow

Single-file conversion

  1. Select the "Select Files" mode
  2. Click the "Browse... " button to choose the HDR/EXR files to convert
  3. Set the output folder (optional, defaults to the input file directory)
  4. Adjust the conversion options (as needed)
  5. Click the "Convert" button to start conversion

Folder batch conversion

  1. Select the "Select Folder" mode
  2. Click the "Browse... " button to choose the folder containing HDR/EXR files
  3. Click the "Scan HDR files" button to scan for files
  4. Set the output folder (optional)
  5. Adjust the conversion options (as needed)
  6. Click the "Convert" button to start conversion

3.1 Format Filter

The format filter converts only files of the specified formats. It supports the following uses:

InputResult
(blank)Convert all .hdr and .exr files
hdrConvert only .hdr files
exrConvert only .exr files
hdr, exrConvert both .hdr and .exr files (same effect as leaving it blank)

3.2 Thumbnail Generation

The thumbnail generation priority:

  1. Search for an existing thumbnail first: look for a .png or .jpg file with the same name in the same directory as the HDR/EXR file
  2. Automatic generation: invoke the image format conversion tool to tone-map the HDR/EXR into a PNG thumbnail
Tip: If you already have a high-quality thumbnail, place it in the same directory as the HDR/EXR file and the tool will use it automatically without regenerating.

4. FAQ

❌ Thumbnails are not generated

The imageio dependency may be missing. Install it following the installation prompt shown in the tool.

❌ Conversion is slow

Decoding HDR/EXR files is computationally expensive. We recommend:

  • Checking "Prefer existing thumbnails"
  • Preparing PNG/JPG thumbnails in advance

❌ Import into current category fails

Make sure to run this tool from the main material library window so it can automatically retrieve the current category path.

❌ Conversion fails when filenames contain Chinese characters

We recommend renaming HDR files to names containing only English letters, digits, and underscores.
