ma-zmetal节点编辑器

本工具用于可视化查看和编辑 Maya .ma 文件和资产管理系统导出的 .zmetal 材质节点文件的节点连接关系。

1. 工具概述

ma-zmetal节点编辑器可以：

  • 打开并可视化 Maya .ma 文件中的节点网络（createNode / connectAttr）
  • 打开并可视化 .zmetal 材质节点文件（资产管理系统导出格式）
  • 在无限画布上以节点图方式展示节点和连接关系
  • 支持手动添加/删除节点和连接
  • 支持拖放 .ma / .zmetal 文件快速打开
  • 支持撤销/重做编辑操作
  • 自动层级布局，从左到右排列节点
  • 保存编辑结果到 .ma 或 .zmetal 格式

3. 使用流程

3.1 打开文件

  1. 点击「打开文件」按钮，或直接将 .ma / .zmetal 文件拖入窗口
  2. 工具自动解析文件，在画布上显示所有节点和连接
  3. 节点以不同颜色区分类型（材质节点、纹理节点、工具节点等）
  4. 节点自动按层级布局排列

3.2 编辑节点

当前支持以下编辑操作：

  • 删除节点/连接：选中后按 Delete 键
  • 折叠节点：点击节点右上角的折叠按钮，隐藏端口区域
  • 撤销/重做：所有编辑操作都支持 Ctrl+Z 撤销和 Ctrl+Y 重做
注意：当前版本暂不支持手动添加新节点。如需添加节点，请先在 Maya 中创建后再打开 .ma 文件编辑。

3.3 连线操作

  1. 点击节点的输出端口（右侧橙色圆点）开始连线
  2. 移动鼠标到目标节点的输入端口（左侧灰色圆点）
  3. 点击输入端口完成连接
  4. 连接线颜色说明：
    • ■ 绿色 — 单属性连接
    • ■ 黄色 — 多属性连接（同一对节点间有多条连线）
    • ■ 灰色 — 选中的连接
  5. 要取消连线，点击空白区域或同一节点的端口

3.4 保存文件

  1. 点击「保存文件」覆盖原文件
  2. 点击「另存为...」可以选择输出格式（.ma 或 .zmetal）
  3. .ma 保存：以原始文件为基底，只删除用户移除的节点，保留几何体、相机等所有其他数据
  4. .zmetal 保存：以原始 JSON 为基底，只更新变动的节点和连接，保留原有的值属性

4. zmetal 格式说明

.zmetal 是资产管理系统（MaterialManagementPro）导出的材质节点数据格式，基于 JSON。

与 .ma 文件的区别：

特性.ma 文件.zmetal 文件
格式Maya ASCII 文本JSON
内容完整场景数据（几何体、动画等）仅材质节点和连接关系
来源Maya 保存的 .ma 文件资产管理插件导出
节点识别正则匹配 createNode / connectAttr直接读取 JSON nodes 字典
体积较大较小，仅含节点数据

6. 常见问题

❌ 打开 .ma 文件后没有显示任何节点

可能原因：

  • 文件不是标准的 Maya ASCII (.ma) 格式
  • 文件中没有 createNode 或 connectAttr 语句
  • 尝试在 Maya 中重新保存为 .ma 格式

❌ 打开 .zmetal 文件后节点显示不完整

.zmetal 文件仅包含材质节点网络数据。如果文件中只有部分节点有连接关系，未连接的独立节点可能不会显示输入/输出端口名。

❌ 在 Maya 中运行后无法正常退出

在 Maya GUI 中运行时，关闭窗口即可。在 mayapy.exe 或普通 Python 中运行时，关闭窗口会自动退出程序。

❌ 连接/编辑操作没有响应

请确保：

  • 输出端口连接到输入端口（橙色 → 灰色），方向不能反
  • 点击端口而非节点空白区域
