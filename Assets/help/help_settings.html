资产库管理

管理多个资产库的位置和名称。支持添加、删除、设为默认操作。

  1. + 添加资产库 — 选择磁盘上的资产库文件夹，输入显示名称
  2. - 删除选中 — 从列表中移除（不删除磁盘文件）。至少保留一个库
  3. ☆ 设为默认 — 标记为 [默认] 的库在插件启动时自动加载
提示：新建的空文件夹在首次切换到该库时自动创建核心目录结构（materials/、models/ 等）。

导出默认值

按资产类型（材质/模型/灯光/贴图/场景/HDR/动态）分别设置导出格式的默认勾选状态。

分组包含格式
材质格式材质节点 (.zmetal)、合并材质、材质映射 (.mcm)
几何体格式Maya ASCII (.ma)、Maya Binary (.mb)、FBX (.fbx)、OBJ (.obj)、USD (.usd)
缓存与代理Alembic (.abc)、Arnold (.ass)、V-Ray (.vrscene)、Redshift (.rs)、V-Ray 代理 (.vrmesh)
作用：新建导出对话框时，各格式的复选框默认值会按当前资产类型读取这些预设。例如模型类资产默认勾选 FBX，材质类默认不勾选几何体。

支持格式

定义哪些文件扩展名被视为可导入的资产文件。每行一个扩展名（不含点号）。

数据存储在 config.json 的 asset_file_extensions 字段。

注意：修改后需点击「应用」生效。错误的配置可能导致资产导入功能异常。

贴图后缀

配置 PBR 贴图类型的文件名匹配规则。

配置项说明
左侧类型列表PBR 贴图类型（albedo / normal / roughness / metallic / ao 等）
右侧别名列表该类型对应的文件名关键词，引擎用这些关键词识别贴图类型

例如：normal 类型的别名包含 _normal、_nrm、_n，文件名 crate_n.png 会被识别为法线贴图。

提示：点击「恢复默认」可重置所有别名为出厂设置。数据来自 Assets/preset/pbr_mapping.json。

常用标签

按子库类型（材质/模型/灯光/贴图/场景/HDR）分别管理常用标签列表。

  • 左侧选择子库类型 → 右侧编辑该类型的标签（每行一个）
  • 标签在导出对话框中以快捷按钮形式呈现，点击即可添加
  • 数据存储在 config.json 的 common_tags 字段

子库与分类

管理子库的 ID、显示名和默认分类列表。支持添加自定义子库、删除自定义子库、从实际文件夹同步分类。

字段说明
子库ID子库的唯一标识符（如 materials），不可与其他子库重复
显示名在 UI 中显示的名称（如"材质"）
默认分类列表首次创建该子库时自动生成的分类文件夹，格式：id 名称

添加子库

右键点击左侧子库列表空白处，选择「添加子库」。新子库的 ID 格式为 custom_N，显示名为「自定义N」。

删除子库

右键点击自定义子库，选择「删除子库」。核心子库（材质、模型、灯光、贴图、场景、HDR、动态）不可删除。

同步分类

点击右侧编辑区上方的「读取当前分类文件夹」按钮，可将当前资产库的实际文件夹结构同步到设置中。此操作会覆盖现有的默认分类列表配置。

编辑分类

在分类树中右键点击分类，选择「编辑」可修改分类的易读名和类型。类型下拉框列出所有子库类型，确保个性化右键菜单能正确识别。

注意：七个核心子库（materials / models / lights / textures / scenes / hdr / ani）不可删除，修改 ID 可能导致已有数据不可用。

高级配置

高级用户自定义文件扩展名识别规则和材质节点类型。

配置项说明
几何体扩展名导入时识别几何体文件的扩展名列表（如 .ma .fbx .obj）
图像/贴图扩展名导入时识别贴图文件的扩展名（如 .png .exr .tga）
材质节点类型导出时识别场景中哪些节点是材质节点（如 standardSurface, VRayMtl）
⚠ 解锁编辑：高级配置默认锁定。勾选底部「解锁编辑」复选框后才能修改。错误的配置可能导致资产库功能异常，请确认清楚每一项的含义后再修改。
