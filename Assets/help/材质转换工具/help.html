材质转换工具 — 使用帮助

本工具用于在 Maya 中进行材质类型之间的批量转换，支持自定义映射关系，可处理大批量场景中的材质替换工作（如将所有 lambert 材质转换为 aiStandardSurface）。

1. 工具概述

工具可以帮你做这些事：

  • 批量转换 — 一次性转换场景中所有匹配的材质
  • 类型映射 — 定义源材质类型到目标材质类型的对应关系
  • 属性映射 — 通过 .mmap 映射文件控制属性传递
  • 预设保存 — 常用映射配置可保存为 .mlist 文件复用
  • 自动搜索 — 自动从映射文件夹中找到对应的 .mmap 映射文件
  • 保留未连接属性 — 默认不删除源材质，方便回退

2. 使用步骤

2.1 配置材质类型映射

  1. 在"材质类型映射配置"表格中，添加源材质类型和目标材质类型的映射关系
  2. 可以双击单元格手动输入材质类型（如 lambert、aiStandardSurface）
  3. 也可以点击"加载源"/"加载目标"按钮从选择的材质节点载入类型
  4. 当只有一行且源为空时，会将所有材质转换为该目标类型
  5. 可以点击"保存预设"将当前配置保存为 .mlist 文件

2.2 选择映射文件

  1. 点击"浏览..."按钮选择包含映射 .mmap 文件的文件夹
  2. 工具会自动加载该文件夹中的所有 .mmap 文件
  3. 映射文件会根据"源材质类型"和"目标材质类型"自动匹配
  4. 点击"打开文件夹"可快速打开映射文件目录进行管理
提示：.mmap 映射文件可以由"材质节点属性映射工具"创建和管理。

2.3 执行转换

  1. 配置好映射关系后，点击"转换选择"按钮 — 仅转换选中的材质
  2. 或点击"转换全部"按钮 — 转换场景中所有符合映射配置的材质
  3. 转换过程中会在底部状态栏显示进度
  4. 完成后会有弹窗提示成功/失败的材质数量
注意：建议在转换前保存场景文件。虽然工具默认不删除源材质，但批量操作前备份是个好习惯。

2.4 转换选项

选项说明

3.2 映射配置表格

配置"源材质类型 → 目标材质类型"的对应关系：

  • 源：要转换的材质类型（如 lambert、phong、blinn）
  • 目标：转换后的材质类型（如 aiStandardSurface、redshiftStandardMaterial）
特殊用法：当只有一行且"源"留空时，会将所有材质都转换为该"目标"类型。这在"全部转换为统一类型"的场景下非常有用。

3.3 映射文件列表

显示当前选择的映射文件夹中找到的所有 .mmap 文件：

  • 文件名：.mmap 文件名（建议使用 源_目标.mmap 命名）
  • 源类型：该映射文件适用的源材质类型
  • 目标类型：该映射文件适用的目标材质类型
  • 规则数：该映射文件中定义的属性映射规则数量

4. 预设管理

预设文件位置

预设文件存放在工具的 preset/ 目录下，扩展名为 .mlist。点击"打开文件夹"可快速定位。

预设文件结构

预设文件是 JSON 格式，包含映射关系列表：

{
  "version": "1.0",
  "mappings": [
    {"source": "lambert", "target": "aiStandardSurface"},
    {"source": "phong", "target": "redshiftStandardMaterial"},
    {"source": "", "target": "aiStandardSurface"}
  ]
}

预设 vs 映射文件

类型扩展名作用
预设（Preset）.mlist保存"源类型 → 目标类型"的对应关系
映射文件（Map）.mmap保存"源属性 → 目标属性"的详细映射规则
配合使用：预设定义"什么类型转什么类型"，映射文件定义"类型之间属性怎么传"。两者配合完成完整转换流程。

5. 使用技巧

  1. 先小范围测试：先用"转换选择"测试一两个材质，确认效果后再用"转换全部"
  2. 统一目标类型：如需将所有材质统一为 PBR 材质，使用"源留空 + 单行"的预设
  3. 复用映射：相同材质类型转换一次后，预设和映射文件可永久复用
  4. 分层处理：复杂场景可分批转换（如先转 lambert，再转 phong）
  5. 检查未匹配：转换完成后查看日志，注意有未被映射的材质
  6. 回退策略：如效果不理想，由于源材质默认保留，可以手动删除目标材质
  7. 团队共享：将 preset/ 目录加入共享路径，统一团队转换标准

6. 常见问题

Q: 转换后材质效果不对？

A: 大多数情况是 .mmap 映射文件不完整。可以使用"材质节点属性映射工具"创建更详细的映射规则。

Q: 找不到对应的 .mmap 文件？

A: 映射文件夹中没有匹配"源_目标"的 .mmap 文件。可以：
1. 在映射文件夹中创建匹配的文件名（如 lambert_aiStandardSurface.mmap）
2. 使用"材质节点属性映射工具"创建新的映射文件

Q: 转换失败了？

A: 检查以下几点：
1. 目标渲染器是否已加载（Arnold / Redshift 插件）
2. 源节点类型名称是否拼写正确（区分大小写）
3. 场景中是否有同名材质导致冲突

Q: 转换很慢？

A: 大场景批量转换会逐个节点处理，属正常现象。可以观察状态栏进度条。如卡死请检查是否有复杂节点网络。

Q: 能撤销转换吗？

A: 工具默认不删除源材质，所以可以手动删除目标材质并重新使用源材质。如需彻底转换请在转换前保存场景。

Q: 支持哪些渲染器？

A: 理论上支持所有 Maya 已加载的渲染器。常用支持：
• Arnold (aiStandardSurface)
• Redshift (redshiftStandardMaterial)
• V-Ray (VRayMtl)
• RenderMan (PxrSurface)
• Stingray (StingrayStandardMaterial)
