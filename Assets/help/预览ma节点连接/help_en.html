ma-zmetal Node Editor

This tool is used to visually view and edit the node connection relationships in Maya .ma files and .zmetal material node files exported by the asset management system.

1. Overview

The ma-zmetal node editor can:

  • Open and visualize the node networks (createNode / connectAttr) in Maya .ma files
  • Open and visualize .zmetal material node files (asset management system export format)
  • Display nodes and connections as a node graph on an infinite canvas
  • Support manually adding/deleting nodes and connections
  • Support dragging and dropping .ma / .zmetal files to open them quickly
  • Support undo/redo for edit operations
  • Automatic hierarchical layout, arranging nodes from left to right
  • Save edit results to .ma or .zmetal format

3. Workflow

3.1 Open File

  1. Click the "Open File" button, or directly drag a .ma / .zmetal file into the window
  2. The tool automatically parses the file and displays all nodes and connections on the canvas
  3. Nodes are distinguished by type with different colors (material nodes, texture nodes, utility nodes, etc.)
  4. Nodes are automatically arranged in a hierarchical layout

3.2 Editing Nodes

The following edit operations are currently supported:

  • Delete nodes/connections: select and press the Delete key
  • Collapse nodes: click the collapse button at the top-right of a node to hide the port area
  • Undo/Redo: all edit operations support Ctrl+Z undo and Ctrl+Y redo
Note: The current version does not support manually adding new nodes. If you need to add nodes, create them in Maya first, then open the .ma file to edit.

3.3 Making Connections

  1. Click a node's output port (the orange dot on the right) to start a connection
  2. Move the mouse to the target node's input port (the gray dot on the left)
  3. Click the input port to complete the connection
  4. Connection line colors:
    • ■ Green — single attribute connection
    • ■ Yellow — multi-attribute connection (multiple lines between the same pair of nodes)
    • ■ Gray — selected connection
  5. To cancel a connection, click an empty area or the port of the same node

3.4 Saving Files

  1. Click "Save File" to overwrite the original file
  2. Click "Save As..." to choose the output format (.ma or .zmetal)
  3. .ma saving: uses the original file as the base, only removes the nodes the user deleted, and preserves all other data such as geometry and cameras
  4. .zmetal saving: uses the original JSON as the base, only updates the changed nodes and connections, and preserves the original value attributes

4. zmetal Format Reference

.zmetal is a material node data format exported by the asset management system (MaterialManagementPro), based on JSON.

Differences from the .ma file:

Feature.ma File.zmetal File
FormatMaya ASCII textJSON
ContentComplete scene data (geometry, animation, etc.)Only material nodes and connection relationships
Source.ma file saved by MayaExported by the asset management plugin
Node recognitionRegex matching of createNode / connectAttrReads the JSON nodes dictionary directly
SizeLargerSmaller, contains only node data

6. FAQ

❌ No nodes are displayed after opening a .ma file

Possible causes:

  • The file is not a standard Maya ASCII (.ma) format
  • The file contains no createNode or connectAttr statements
  • Try re-saving the file as .ma format in Maya

❌ Nodes are displayed incompletely after opening a .zmetal file

A .zmetal file only contains the material node network data. If only some nodes in the file have connection relationships, unconnected standalone nodes may not display their input/output port names.

❌ Cannot exit normally after running inside Maya

When running inside the Maya GUI, just close the window. When running under mayapy.exe or ordinary Python, closing the window will automatically exit the program.

❌ Connection/edit operations do not respond

Please ensure:

  • Output ports connect to input ports (orange → gray); the direction cannot be reversed
  • Click the port, not the empty area of the node
