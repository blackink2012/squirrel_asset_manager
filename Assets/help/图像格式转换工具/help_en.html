Image Format Converter

This tool uses OpenCV for batch conversion of HDR/EXR/TIFF/PNG/JPEG and other formats, supporting resolution adjustment, format conversion, and preservation of the folder hierarchy.

1. Overview

The image format converter can:

  • Batch convert multiple image formats (HDR, EXR, PNG, JPEG, TIFF, BMP, WebP, TGA)
  • Automatically tone map when converting from HDR/EXR floating-point formats to 8-bit formats
  • Support custom output resolution
  • Preserve the original folder hierarchy structure
  • Automatically clean filenames that do not conform to Maya conventions
  • Display conversion logs and progress in real time

4. Workflow

Single File Conversion Workflow

  1. Select the "Select Files" mode
  2. Click the "Browse..." button to choose the image file(s) to convert
  3. Set the output folder (optional; defaults to the input file directory)
  4. Choose the target format
  5. Adjust resolution and other options (as needed)
  6. Click the "Start Conversion" button to begin

Folder Batch Conversion Workflow

  1. Select the "Select Folder" mode
  2. Click the "Browse..." button to choose the folder containing image files
  3. Set the input format filter (optional)
  4. Set the output folder (optional)
  5. Choose the target format
  6. Adjust resolution and other options (as needed)
  7. Click the "Start Conversion" button to begin

4.1 HDR Tone Mapping

When converting from HDR/EXR floating-point formats to 8-bit formats (such as PNG, JPEG), the tool automatically performs tone mapping:

1. Apply Reinhard tone mapping: image = image / (image + 1.0)
2. Apply Gamma correction: image = pow(image, 1.0 / 2.2)
3. Convert to 8-bit: image = image * 255
Tip: Converting HDR to 8-bit formats loses dynamic range. It is recommended for previews or thumbnail generation.

4.2 Resolution Adjustment

Resolution adjustment rules:

  • Only width set: height is computed proportionally
  • Only height set: width is computed proportionally
  • Both width and height set: scales by the smaller ratio to fit (when keeping aspect ratio)
  • Keep aspect ratio off: forcibly stretches to the specified size

4.3 Filename Cleanup

The tool automatically cleans filenames that do not conform to Maya conventions:

  • Keeps: letters, digits, underscores, and periods
  • Other characters are replaced with an underscore _
  • The first character must be a letter; otherwise it is replaced with a random letter
Note: Filename cleanup modifies the source files! If a source file does not conform to Maya conventions, the tool will automatically rename it.

5. FAQ

❌ EXR files cannot be read

This may be due to a missing imageio dependency. EXR reading prefers OpenCV, and falls back to imageio if that fails. It is recommended to install imageio for better EXR compatibility.

❌ Colors look wrong after conversion

Tone mapping is applied when converting HDR/EXR to 8-bit formats, which may cause colors to differ from the original file. If you need to preserve colors exactly, keep the original format or use a professional image processing application.

❌ Filenames were modified automatically

Maya requires filenames to contain only letters, digits, underscores, and periods, and to start with a letter. Files that do not conform are automatically renamed.

❌ Conversion is slow

Decoding HDR/EXR files requires a lot of computation. It is recommended to:

  • When using folder mode, exclude files you do not need to convert via the format filter
  • Avoid converting many high-resolution EXR files at once

❌ Out of memory

Processing extremely large images can cause out-of-memory errors. It is recommended to:

  • Set an output resolution to limit image size
  • Convert in batches; do not process too many files at once

❌ The output folder does not exist

The tool automatically creates the output folder; there is no need to create it manually.
