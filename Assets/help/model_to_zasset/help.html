模型资产转zasset工具 - 使用帮助

一、工具概述

本工具用于将各种3D模型格式（ma、mb、obj、usd、abc、fbx等）转换为统一的.zasset资产格式，便于资产管理和快速调用。

  • 支持 同名多格式文件 合并为一个资产
  • 自动收集依赖文件（贴图、材质等）
  • 支持读取现有资产管理工具的元数据（如 Zoo Tools 的 json）
  • 保留源文件名，不做修改
  • 用户可自定义目标格式
  • 支持递归搜索深层目录中的模型文件
  • 支持包含 ass/、textures/ 等子文件夹内容

二、支持的模型格式

格式扩展名说明
Maya ASCII.maMaya 文本格式场景文件
Maya Binary.mbMaya 二进制格式场景文件
USD.usd, .usda, .usdc通用场景描述格式
Alembic.abc动画缓存格式
FBX.fbxAutodesk 通用交换格式
OBJ.objWavefront 几何格式
Arnold Proxy.assArnold 渲染器代理文件
默认优先级：ma > mb > usd > usda > usdc > abc > fbx > obj > ass

三、界面说明

3.1 输入设置

模型文件夹：选择包含模型文件的文件夹，工具会自动扫描其中的模型文件。

3.2 输出设置

输出位置：选择转换后的 zasset 文件存放位置。如果不设置，将输出到当前资产库选中的分类文件夹。

3.3 转换选项

  • 目标格式：逗号分隔的格式列表，如 ma,usd,abc。留空则打包所有已发现的格式。
  • 包含子文件夹：勾选后扫描 ass/、textures/、sourceimages/ 等子目录中的文件，并将其打包进 zasset。
  • 递归搜索子文件夹：勾选后扫描深层目录中的模型文件（适用于多个资产在子文件夹中整理好的场景）。
  • 包含依赖文件：勾选后自动收集 .ma 文件中引用的贴图、材质文件。
  • 使用现有元数据和缩略图：勾选后读取 json 等元数据文件和现有缩略图。

3.4 文件路由配置

定义模型文件和依赖文件在 zasset 内部的目录结构。可添加自定义路由规则，指定扩展名对应的目标文件夹。

  • root：模型文件（ma, mb, obj, usd, abc, fbx, mcm, zmetal, mtl）
  • textures：贴图文件（jpg, png, exr, tga, hdr, dds 等）
  • ass：Arnold 代理文件

3.5 元数据源配置

配置缩略图搜索路径和元数据源，用于从现有资产管理工具（如 Zoo Tools）的资产格式中提取信息。

  • 缩略图搜索路径：支持 {assetName} 变量替换的动态路径模式
  • 元数据源：定义文件路径模板、格式和字段映射规则

3.6 模型预览

右侧面板显示扫描到的模型资产列表和子文件夹内容预览。选中资产后可查看其包含的文件格式和大小。

四、使用流程

步骤一：准备源文件

将模型文件放入同一文件夹中。同名不同格式的文件被视为同一资产。

步骤二：选择输入文件夹

点击"浏览..."选择文件夹，工具自动扫描模型文件。

步骤三：配置选项

设置目标格式、子文件夹包含、递归搜索等选项。

步骤四：点击"扫描模型"

查看扫描结果和子文件夹内容预览。

步骤五：点击"转换"

工具自动收集文件、读取元数据、生成缩略图、构建 zasset。

五、资产命名规则

工具以文件名（不含扩展名）作为资产名称，保留原始文件名不变。

源文件资产名称
SciFi_Fighter_BLNN.maSciFi_Fighter_BLNN
subdir/character_v1.macharacter_v1（递归模式下显示为 subdir/character_v1）
同名多格式处理：aaa.ma、aaa.mb、aaa.obj、aaa.usd 视为同一个资产，所有格式打包进同一 zasset。

六、子文件夹内容包含

3D资产常将 Arnold 代理缓存、序列贴图、文件依赖等放在子文件夹中。工具支持自动扫描并包含这些文件。

6.1 默认子文件夹

子文件夹内容
ass/Arnold 代理文件（.ass 缓存序列）
textures/贴图文件
sourceimages/Maya 标准贴图目录

子文件夹内容保持原有相对路径结构打包到 zasset 中：

pSphere1.zasset/
├── meta.json
├── pSphere1.ma
├── ass/pSphere1_1001.ass    ← 保持 ass/ 目录结构
└── textures/dd_diffuse.png  ← 保持 textures/ 目录结构

七、依赖文件收集

工具通过以下方式收集依赖文件：

  1. 解析 .ma 文件：读取 Maya ASCII 文件中的贴图引用路径
  2. 同目录扫描：搜索与资产同名的 .mtl、.mcm、.zmetal 文件
  3. 标准路径搜索：在 textures/、sourceimages/ 目录中搜索贴图

支持的贴图格式：.jpg, .jpeg, .png, .tga, .tif, .tiff, .exr, .hdr, .bmp, .tx, .dds

工具自动创建 texture_map 字段记录原始路径到 zasset 内部路径的映射：

"texture_map": {
    "C:/Projects/textures/my_diffuse.jpg": "textures/my_diffuse.jpg"
}

十、配置文件说明

工具使用 model_mapping.json 配置文件，位于工具同目录下：

  • category_mapping：根据资产名称关键词自动推断分类
  • file_routing：定义不同类型文件的目标目录
  • thumbnail_search_paths：缩略图搜索路径模式
  • metadata_sources：元数据源文件路径模板和字段映射
  • format_priority：格式优先级顺序

十一、常见问题

Q: 为什么模型没有被识别？

A: 确保文件扩展名在支持列表中（.ma, .mb, .obj, .usd, .usda, .usdc, .abc, .fbx, .ass）。

Q: 贴图没有被正确收集？

A: 确认 .ma 文件中包含贴图引用路径，贴图文件在同一目录或 textures/ 中，并勾选了"包含依赖文件"。

Q: 子文件夹内容没有被包含？

A: 确认勾选了"包含子文件夹"，且子文件夹名称在列表中（默认 ass, textures, sourceimages）。

Q: 如何只转换特定格式？

A: 在"目标格式"输入框中填写逗号分隔的格式列表，如 ma,usd,abc。

Q: 元数据没有被读取？

A: 确认 json 文件存在于 *_Dependencies/ 或 *_ma_Dependencies/ 目录中。

十二、依赖安装

需要以下 Python 库：

  • PIL/Pillow（缩略图生成）
  • PySide2/PySide6（UI 界面）

安装方法：

# 系统终端
pip install Pillow

# Maya 环境
"C:\Program Files\Autodesk\Maya2025\bin\mayapy.exe" -m pip install Pillow
