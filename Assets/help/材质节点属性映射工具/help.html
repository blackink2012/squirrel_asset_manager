材质节点属性映射工具 — 使用帮助

本工具用于定义 Maya 材质节点之间的属性映射关系，支持设置默认值和转换函数。主要用于不同渲染器材质类型之间的属性转换（如 lambert → aiStandardSurface）。

1. 工具概述

工具可以帮你做这些事：

  • 自动加载节点属性 — 设置源/目标节点类型后，下拉列表自动填充该类型的所有可读写属性
  • 批量映射 — 通过表格一次性配置多个属性映射关系
  • 值转换 — 支持简单的转换函数（如 1-x 反转粗糙度）
  • 预设保存/加载 — 映射配置可保存为 .mmap 文件，下次快速恢复
  • 反向映射 — 一键互换源和目标角色
  • 属性浏览器 — 独立窗口查看场景中节点的所有属性及当前值

2. 快速上手

典型使用流程

  1. 设置源节点类型：在 Maya 中选中一个源材质节点，点击源"浏览"按钮；也可以直接在文本框中输入节点类型（如 lambert）
  2. 设置目标节点类型：用同样的方式设置目标类型（如 aiStandardSurface）
  3. 添加映射行：点击"添加行"按钮，每行的下拉列表会自动填充对应类型的属性
  4. 配置映射：在每行中选择源属性、目标属性，必要时填写转换函数和默认值
  5. 保存预设：点击"保存预设"将映射配置存为 .mmap 文件
提示：未设置节点类型时，"添加行"按钮也可以工作，但下拉列表为空。可以后续手动输入属性名。

4. 右键菜单

工具提供两处右键菜单：

  • 表格单元格右键：在源属性列或目标属性列上右键，可快速"清空源属性"或"清空目标属性"
  • 整体表格右键：在空白处右键，可执行"反向映射"、"清空表格"、"加载示例数据"、"加载预设"等

5. 转换函数

"转换函数"列用于在属性值传递时执行简单的数学变换，例如：

场景转换函数说明
反转粗糙度1-xMaya 的 roughness 是 1-roughness 关系时使用
归一化x/255从 0-255 映射到 0-1
反归一化x*255从 0-1 映射到 0-255
伽马校正x**2.2线性→sRGB 转换
注意：转换函数使用 Python 表达式语法，输入 x 表示当前属性值。只支持简单的数学运算，不支持函数调用或自定义函数。
默认值：当目标属性无值时使用的默认值。例如 0.5、(0,0,0)、"" 等。

6. 预设管理

预设文件位置

预设文件存放在工具的 preset/ 目录下，扩展名为 .mmap。可以通过界面底部的"打开文件夹"按钮快速定位。

预设文件命名

建议使用 源类型_目标类型.mmap 的命名格式，例如：

  • lambert_aiStandardSurface.mmap
  • phong_redshiftStandardMaterial.mmap
  • standardSurface_arnold.mmap

预设文件结构

预设文件是 JSON 格式，包含：

{
  "source_type": "lambert",
  "target_type": "aiStandardSurface",
  "mappings": [
    {"source": "color", "target": "baseColor", "transform": "", "default": ""},
    {"source": "transparency", "target": "opacity", "transform": "", "default": "1.0"},
    ...
  ]
}

8. 使用技巧

  1. 快速填充属性：先设置源/目标节点类型，再点击"添加行"，下拉列表会自动出现该类型的所有属性
  2. 批量多选删除：勾选多行前的复选框，然后点击"移除选中行"可一次删除多行
  3. 反向映射复用：完成 A → B 的映射后，点击"反向映射"即可得到 B → A 的配置（注意转换函数需要手动调整）
  4. 复杂值转换：如需复杂逻辑（条件判断、字符串处理等），请使用 Maya 自带的连接表达式或脚本
  5. 预设版本管理：预设文件是纯 JSON，可以用 Git/SVN 进行版本管理
  6. 多人协作：将 preset/ 目录加入共享路径，团队成员可以使用同一套映射

9. 常见问题

Q: 为什么下拉列表是空的？

A: 需要先设置源/目标节点类型（点击"浏览"按钮或手动输入）。节点类型决定了下拉列表的内容。

Q: 属性浏览器有什么作用？

A: 用于快速查看场景中选中节点的所有属性及当前值。可以在"转换函数"列编写时参考实际值。也可以从浏览器中拖拽属性到表格中。

Q: 转换函数支持哪些语法？

A: 支持 Python 数学表达式，使用 x 表示当前属性值。例如 1-x、x*2、x**0.5。

Q: 预设文件可以跨工具使用吗？

A: .mmap 预设是工具专有格式，不能直接用于其他工具。但其 JSON 结构简单，可以编写脚本进行转换。

Q: 反向映射后转换函数会怎样？

A: 转换函数保持原样，不会自动反转。如果原函数是 1-x，反向时可能需要改为 x 或反向函数。
