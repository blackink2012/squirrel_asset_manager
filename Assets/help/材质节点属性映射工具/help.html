材质节点属性映射工具

适用于 Maya 2022 及以上版本 · PySide6 / PySide2

材质节点属性映射工具用于在 Maya 中为不同材质节点类型之间建立属性映射关系： 将源材质（如 Arnold 的 aiStandardSurface）的属性，映射到目标材质（如 V-Ray 的 VRayMtl）的对应属性， 并可附加转换函数（如光泽度转粗糙度）与默认值。支持人工逐行配置、AI 智能映射自动推断， 以及 .mmap 预设的保存 / 加载 / 复用。

一、界面布局

1. 顶部工具栏

  • 添加行：在表格末尾添加一行映射，若已设置源/目标节点类型，自动获取该类节点的可读写可见属性作为下拉选项。
  • 删除选中：删除表格中选中的行。
  • 属性浏览器：基于 Maya 中当前选中的物体，浏览其可用属性并填入当前行（需先在 Maya 中选中物体）。
  • AI 智能映射：对表格中所有源属性调用 AI 推断目标属性 / 转换函数 / 默认值。
  • 帮助：打开本帮助文档。
  • 保存预设 / 加载预设：将当前映射保存为 .mmap 文件，或从文件载入映射。

2. 节点类型区

  • 源节点：在 Maya 中选中源材质节点后点击「加载」，自动识别节点类型并填充源属性列表；「清空源属性」恢复为空。
  • 目标节点：同样操作载入目标节点；另有「载入默认值」按钮，将所选目标节点上各目标属性的当前值填入「默认值」列（需先在 Maya 中选择类型一致的目标节点）。

3. AI 服务配置

  • AI 服务：下拉选择服务商——Ollama（本地） / DeepSeek / 通义千问（阿里云 DashScope）。
  • API Key：本地 Ollama 无需填写；DeepSeek / 通义千问需填写对应平台的 API Key（以密码框形式保存）。
  • AI 模型：可编辑下拉框，选择或手动输入模型名；点击「刷新」从服务商拉取可用模型列表。

4. 映射表格

共 5 列：选择 / 源材质属性 / 目标属性 / 转换函数 / 默认值。 支持多选行、右键菜单（对单行执行 AI 判断 / 清空单元格等）。

5. 搜索与底部操作区

  • 搜索框：按关键字实时过滤表格行。
  • 预设路径：显示预设保存目录，点击「打开文件夹」直达。
  • 反向映射：一键交换源 / 目标节点类型与表格中的属性。
  • 清空表格：清空全部映射行。
  • 加载示例：填入一组内置示例数据，便于快速了解用法。

二、快速使用流程

  1. 在 Maya 中选中源材质节点，点击源节点「加载」；再选中目标材质节点，点击目标节点「加载」。
  2. 表格下拉框会自动带上两类节点的属性；也可用「属性浏览器」或手动逐行添加 / 修改。
  3. 逐行为每条源属性指定目标属性、转换函数（如需）与默认值（可点「载入默认值」批量获取当前值）。
  4. 点击「保存预设」将映射存为 .mmap，下次通过「加载预设」直接复用。
自动记忆：关闭窗口时自动保存到 _last_preset.mmap，下次打开工具自动恢复上次的映射配置。

三、AI 智能映射

使用步骤

  1. 确认已载入源 / 目标节点类型，且表格中已存在源属性行。
  2. 在「AI 服务」中选择服务商：本地 Ollama、DeepSeek 或 通义千问；云端服务需填入 API Key。
  3. 选择模型（可点「刷新」获取服务商可用模型列表），确认 AI 服务可用。
  4. 点击「AI 智能映射」。工具会读取源节点类型、目标节点类型、源属性列表、目标可用属性列表与转换函数清单， 交给大模型逐条推断「目标属性」与「转换函数」，自动填入表格，随后可人工微调。
单行 AI 判断：在表格中右键某一行，可只对该行执行 AI 推断，无需整表映射。

Ollama 本地使用提示

  • 需先安装并启动 Ollama，并 ollama pull 目标模型（默认地址 http://localhost:11434）。
  • 工具默认模型为 qwen3-vl:8b，若本机未拉取该模型，请在模型下拉框中改用已安装的模型（如 qwen3.5:4b），或执行 ollama pull qwen3-vl:8b。
  • qwen3 系列属思考型模型，默认会先输出推理过程。工具已自动改用 Ollama 原生接口并关闭思考（think=false），确保直接返回结果 JSON。

五、预设文件说明

  • 预设为 .mmap 格式（JSON），默认保存在 Assets/material_mapper_presets 目录，命名规则 源节点类型_目标节点类型.mmap。
  • 预设包含源 / 目标节点类型、创建日期与完整映射列表，便于团队间共享映射方案。
  • 点击「打开文件夹」可直接查看预设目录。

六、常见问题

1. AI 映射提示「AI 未返回有效的映射结果」

  • 本地 Ollama：确认服务已启动、所选模型已 ollama pull；尝试点「刷新」更新模型列表后重新选择。
  • 云端服务：检查 API Key 是否正确、网络是否可访问该服务商。
  • 源属性过多时大模型可能超时，可分批（分多行选中）执行单行 / 局部 AI 映射。
  • 若在 Maya Script Editor 中看到 [OllamaMapper] 日志，可据此判断响应内容，辅助排查。

2. 提示「无法连接 AI 服务」

Ollama 场景请确认本地服务运行中（浏览器访问 http://localhost:11434 有响应）； 云端场景请确认 API Key 与网络配置。

3. 属性下拉列表为空

请确认已通过「加载」载入源 / 目标节点；某些节点类型无可见可写属性时列表可能为空，此时可改用「属性浏览器」逐属性添加。
