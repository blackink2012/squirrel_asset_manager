Batch Mirror Copy Tool

This tool mirrors files of the specified formats from the source folder to the target folder while preserving the complete directory hierarchy. It is useful for asset archiving, file distribution, and directory structure backup.

1. Tool Overview

The Batch Mirror Copy Tool can:

  • Filter and batch-copy files by file extension
  • Preserve the complete directory hierarchy of the source folder
  • Skip files that already exist at the target location to avoid duplicate copying
  • Support a preview mode to view the list of files that will be copied in advance
  • Display copy progress and operation logs in real time
  • Run in a background thread so the interface stays responsive
  • Use shutil.copy2 to preserve file metadata (e.g. modification time)

2. Core Features

FeatureDescription
Mirror copyCopies matching files from the source folder to the target folder by their relative path, keeping the directory structure unchanged
Format filterFilters which files to copy by file extension; multiple formats are supported, comma-separated
Skip existingFiles already present at the target location are skipped automatically and never overwritten
Preview modeOnly displays the list of files that would be copied; no actual copy operation is performed
Progress trackingReal-time progress bar + detailed operation log, with a summary popup when finished

3. Interface

3.1 Source Folder

Select the source folder from which files will be copied. All matching files are copied according to their relative paths within the source folder.

3.2 Target Folder

Select the folder to which the files will be copied. The tool automatically rebuilds the source folder's directory structure in the target folder.

Note: The source folder and the target folder must not be the same; otherwise the operation is rejected.

3.3 File Formats

Specify the file extensions to copy; separate multiple formats with commas. Extensions are case-insensitive and may or may not include a leading dot.

InputResult
.exr, .hdr, .png, .jpgCopies EXR, HDR, PNG, and JPEG files (default value)
exr, hdrCopies only EXR and HDR files (dot added automatically)
.tif, .tiff, .exrCopies TIFF and EXR files

3.4 Preview Options

When "Preview only (no actual copy)" is checked, clicking Start Copy only scans the files and lists the matching results without performing any copy operation.

3.5 Action Buttons

ButtonFunction
Start CopyScans the source folder and starts the mirror copy (or preview)
Clear LogClears the contents of the operation log area

3.6 Progress and Log

  • Progress label: shows the current processing state (Waiting / Scanning / Processing / Done)
  • Progress bar: shows the overall completion percentage
  • Operation log: records each operation with a timestamp, including copies, skips, failures, and more

4. Workflow

Standard copy workflow

  1. Click the "Browse" button next to the source folder to select the source folder to copy
  2. Click the "Browse" button next to the target folder to select the target folder
  3. Enter the file extensions to copy in the format input box (separate multiple with commas)
  4. (Optional) Check "Preview only" to view the matching results in advance
  5. Click the "Start Copy" button to begin the operation
  6. Watch the progress bar and operation log, and wait for completion
  7. A statistical summary dialog appears when finished

4.1 Preview Mode

Preview mode does not actually copy any files; it is only used to see which files in the source folder would be matched and copied. It is useful for:

  • Confirming that the file format filter is configured correctly
  • Understanding the total number and size of files that would be copied
  • Verifying that the directory structure matches expectations
Tip: In preview mode, the number of matched files matches the actual copy count, so you can accurately evaluate the scale of the operation.

5. FAQ

Can the source folder and target folder be the same?

No. The tool detects whether the source and target folders are the same and rejects the operation with an error message if they are.

What happens if the target file already exists?

The tool automatically skips files that already exist at the target location and never overwrites them. Each skipped record is shown in the operation log with the [Skipped] marker.

What if a copy fails?

A single failed file copy does not interrupt the whole process; the tool continues processing the remaining files. When the operation finishes, a statistical summary dialog lists all failed files and their error reasons for troubleshooting.

How is the directory structure preserved?

The tool computes the path of each file relative to the root of the source folder and rebuilds the same relative path in the target folder. For example, maps/diffuse/color.exr in the source folder is copied to target folder/maps/diffuse/color.exr.

Is file metadata preserved?

The tool copies using shutil.copy2, which preserves file metadata such as the modification time as much as possible.

Does the interface freeze during copying?

No. The copy operation runs in a separate background thread, and the interface updates by polling the progress queue on a timer (100ms interval), keeping the response smooth.

Can a large number of files be copied?

Yes. The tool uses os.walk to recursively scan the source folder, with no hard limit on the number of files. However, when processing many files, the scanning stage may take some time.
