Material Converter — Help

This tool is used to batch convert between material types in Maya, with support for custom mapping relationships. It can handle material replacement in large scenes (e.g., converting all lambert materials to aiStandardSurface).

1. Overview

This tool can help you:

  • Batch conversion — convert all matching materials in the scene at once
  • Type mapping — define correspondences from source material types to target material types
  • Attribute mapping — control attribute transfer through .mmap mapping files
  • Preset saving — commonly used mapping configurations can be saved as .mlist files for reuse
  • Automatic search — automatically find the corresponding .mmap mapping file in the mapping folder
  • Keep unconnected attributes — source materials are not deleted by default, making it easy to roll back

2. Workflow

2.1 Configure Material Type Mappings

  1. In the "Material Type Mapping Config" table, add mapping relationships between source and target material types
  2. You can double-click a cell to manually enter a material type (e.g., lambert, aiStandardSurface)
  3. You can also click the "Load Source"/"Load Target" buttons to load a type from a selected material node
  4. When there is only one row and the source is empty, all materials are converted to that target type
  5. You can click "Save Preset" to store the current configuration as a .mlist file

2.2 Select Mapping Files

  1. Click the "Browse..." button to select a folder containing .mmap mapping files
  2. The tool automatically loads all .mmap files in that folder
  3. Mapping files are automatically matched based on the "source material type" and "target material type"
  4. Click "Open Folder" to quickly open the mapping file directory for management
Tip: .mmap mapping files can be created and managed by the "Material Node Attribute Mapper" tool.

2.3 Run the Conversion

  1. After configuring the mapping, click the "Convert Selected" button — only converts the selected materials
  2. Or click the "Convert All" button — converts all materials in the scene that match the mapping configuration
  3. Progress is shown in the status bar at the bottom during conversion
  4. When complete, a dialog reports the number of successful/failed materials
Note: It is recommended to save your scene file before converting. Although the tool does not delete source materials by default, backing up before batch operations is a good habit.

3.2 Mapping Config Table

Configures the "source material type → target material type" correspondence:

  • Source: the material type to convert (e.g., lambert, phong, blinn)
  • Target: the material type after conversion (e.g., aiStandardSurface, redshiftStandardMaterial)
Special usage: When there is only one row and the "Source" is left empty, all materials are converted to that "Target" type. This is very useful for "convert everything to one unified type" scenarios.

3.3 Mapping File List

Shows all .mmap files found in the currently selected mapping folder:

  • Filename: the .mmap filename (recommended naming: source_target.mmap)
  • Source Type: the source material type that this mapping file applies to
  • Target Type: the target material type that this mapping file applies to
  • Rule Count: the number of attribute mapping rules defined in this mapping file

4. Preset Management

Preset File Location

Preset files are stored in the tool's preset/ directory with the .mlist extension. Click "Open Folder" to locate them quickly.

Preset File Structure

The preset file is in JSON format and contains a list of mapping relationships:

{
  "version": "1.0",
  "mappings": [
    {"source": "lambert", "target": "aiStandardSurface"},
    {"source": "phong", "target": "redshiftStandardMaterial"},
    {"source": "", "target": "aiStandardSurface"}
  ]
}

Presets vs. Mapping Files

TypeExtensionPurpose
Preset.mlistSaves the "source type → target type" correspondence
Map.mmapSaves the detailed "source attribute → target attribute" mapping rules
Using them together: the preset defines "which type converts to which type", and the mapping file defines "how attributes are transferred between types". Together they complete the full conversion workflow.

5. Usage Tips

  1. Test small first: test one or two materials with "Convert Selected" first, then use "Convert All" once you confirm the result
  2. Unify target types: to convert all materials to a PBR material, use a preset with "empty source + single row"
  3. Reuse mappings: once the same material types have been converted, the presets and mapping files can be reused forever
  4. Process in stages: complex scenes can be converted in batches (e.g., convert lambert first, then phong)
  5. Check unmatched: review the log after conversion and watch for materials that were not mapped
  6. Rollback strategy: if the result is not ideal, since source materials are kept by default, you can manually delete the target materials
  7. Team sharing: add the preset/ directory to a shared path to unify the team's conversion standard

6. FAQ

Q: The material does not look right after conversion?

A: In most cases the .mmap mapping file is incomplete. You can use the "Material Node Attribute Mapper" tool to create more detailed mapping rules.

Q: The matching .mmap file cannot be found?

A: There is no .mmap file matching "source_target" in the mapping folder. You can:
1. Create a file with a matching name in the mapping folder (e.g., lambert_aiStandardSurface.mmap)
2. Use the "Material Node Attribute Mapper" tool to create a new mapping file

Q: The conversion failed?

A: Check the following:
1. Whether the target renderer is loaded (Arnold / Redshift plugin)
2. Whether the source node type name is spelled correctly (case-sensitive)
3. Whether there are materials with the same name in the scene causing conflicts

Q: The conversion is very slow?

A: Batch conversion in large scenes processes each node one by one, which is normal. You can watch the progress bar in the status bar. If it appears frozen, check for complex node networks.

Q: Can I undo the conversion?

A: The tool does not delete source materials by default, so you can manually delete the target materials and reuse the source materials. For a thorough conversion, save your scene before converting.

Q: Which renderers are supported?

A: In theory, all renderers loaded in Maya are supported. Common supported renderers:
• Arnold (aiStandardSurface)
• Redshift (redshiftStandardMaterial)
• V-Ray (VRayMtl)
• RenderMan (PxrSurface)
• Stingray (StingrayStandardMaterial)
