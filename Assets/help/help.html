MaterialManagementPro 使用帮助

1. 插件整体结构

MaterialManagementPro 是 Maya 2025 的材质与资产管理插件，插件文件夹名为 squirrel_asset_manager。

双库架构

标签页用途存储位置
Category 库长期积累的分类素材库，按类别整理系统级目录 AssetLibrary/category_library/
Project 库当前项目专属资产，按项目隔离项目内 AssetLibrary/project_library/

两个库完全独立，资产不能跨库拖拽或复制。

六大子库

每个库下包含 6 个子库：材质、模型、贴图、灯光、场景、HDR。每个子库可自定义分类层级。

资产格式

所有资产统一为 .zasset 单文件 ZIP 格式，内含元数据（meta.json）、缩略图（thumb.sicon / thumb.mp4）、材质数据（node.zmetal）、几何体（node.ma/fbx/abc...）和贴图（textures/ 目录）。一个文件即一个完整资产。

2. 导出资产

导出是将 Maya 场景中的材质、模型或物体打包为 .zasset 资产的过程。点击 "导出资产" 按钮打开导出对话框（详细按钮说明见对话框中的 "?" 帮助）。

2.1 三种导出模式

模式适用场景行为
单资产选 1 个或多个物体合并为 1 个资产弹出对话框 → 指定名称/分类 → 交互截图 → 导出
全自动选 N 个物体每个独立为资产首资产交互取景 → 后续自动复用 → 全部导出
半自动选 N 个物体每个独立导出每个资产弹出截图 UI → 手动确认 → 下一个

2.2 三种缩略图来源

来源速度质量适合
截屏工具最快视口截图模型、贴图等大多数资产
Maya 拍屏较快视口 playblast需要动画预览的资产
渲染图最慢Arnold 渲染高质量材质/场景
时间轴：拍屏/渲染图 + 时间轴 → MP4 动图。缩略图在所有资产导出后统一生成，不中断几何体导出。

2.3 支持的导出格式

类别格式说明
几何体ma / mb / fbx / obj / usd标准建模格式
缓存abc (Alembic)动画缓存
代理ass / rs / vrscene渲染器代理

2.4 时间轴动画导出

勾选"时间轴"：abc/usd/ass/rs/vrscene 导出完整动画。渲染图逐帧合成 MP4（⚠️ 可能耗时数分钟，Maya 暂时无响应属正常）。

3. 导入资产

3.1 从外部文件导入

  1. 工具栏 "导入" → "从文件导入"（或 "从文件夹导入"）
  2. 选择 Maya 文件或贴图文件，自动创建 .zasset 添加到当前分类
  3. 导入文件夹时按名称自动分组，每组对应一个 .zasset

3.2 从库导入到场景

右键资产弹出菜单：

菜单项效果
导入到场景自动选择最合适的格式导入
导入 → .zmetal重建完整着色网络（节点、属性、连接、贴图）。材质名保持原名，冲突时 Maya 自动加数字编号
导入 → .mcm导入材质 + 自动匹配赋予选中物体（见 3.3）
导入 → .ma/.fbx/.obj/...按指定格式导入几何体
导入 → .ass/.rs/.vrscene创建渲染器代理引用节点
.zmetal 原理：记录 Maya 材质网络的完整信息。导入时在场景中重建整个着色网络。原始 Maya 文件不存在也能还原材质。

3.3 MCM 材质匹配

.mcm 记录物体拓扑特征（顶点数、面数、边数），导入时通过三维特征精确匹配，自动赋予材质。

典型场景：abc/obj 等格式不包含材质数据。导入后物体无材质 → 选中物体 → 右键 "导入 → .mcm"
  1. 先导入 .zmetal（重建材质网络）
  2. 计算选中物体顶点/面/边数
  3. 在 .mcm 中查找三维特征精确匹配的原物体
  4. 将材质自动赋予选中物体（含面级分配）
前提：必须在 Maya 中选中目标物体。顶点/面/边数必须与原模型完全相同（无三角化、合点等）。资产导出时必须勾选 .mcm 复选框。

3.4 资产管理操作

  • 复制/粘贴：跨分类粘贴。必须通过插件菜单
  • 重命名：右侧属性面板修改后回车。不要直接改 .zasset 文件名
  • 删除：二次确认
  • 导出 .zasset：复制到指定文件夹用于跨库迁移或备份
⚠️ 禁止：手动复制/移动/重命名 .zasset 文件。插件用数据库管理，手动操作导致资产不可见。

4. 常见问题

❌ 手动复制 .zasset 文件

复制的资产在插件中不显示。正确：右键 → 复制 → 粘贴。

❌ 直接重命名 .zasset

资产消失。正确：属性面板修改名称后回车。

❌ 删除插件文件夹

分类下资产集体消失。正确：插件内逐个删除。

❌ 跨库拖拽

Category 和 Project 独立。正确：导出 .zasset → 目标库导入。

❌ 时间轴 + 渲染图后 Maya 卡死

正常渲染过程，等待完成。急用选拍屏。

❌ 导入 abc/obj 无材质

选中物体 → 右键 → 导入 → .mcm（资产须含 .mcm）。

❌ MCM 匹配失败

顶点/面/边数与原模型不一致（可能三角化/合点过）。确保拓扑完全一致。

❌ 导入后贴图路径错误

重新导出该资产（贴图自动重定向到项目 sourceimages 目录）。
