# 个性化双击命令设计方案

## 概述

在设置对话框的"右键菜单"标签页中，新增双击命令配置区域，允许用户为每个子库分别设置双击缩略图时执行的命令（单选），主要用于快速导入和创建资产。

## 设计决策

| 项目 | 决策 |
|------|------|
| **配置粒度** | 按子库类型（materials / models / textures / lights / hdr / scenes / ani / 自定义） |
| **UI 布局** | 合并到现有"右键菜单"标签页，左侧子库列表不变，右侧上方保持右键菜单复选框，下方新增双击命令单选按钮组 |
| **交互方式** | QRadioButton 单选（含"无操作"默认项） |
| **存储文件** | 独立文件 `Assets/preset/double_click_preset.json` |
| **各子库命令范围** | 仅导入/创建资产相关命令（不含收藏夹/全选/复制等非导入操作） |
| **自定义库** | 列出通用项：无操作、导入、导入几何体、创建资产 |

## 各子库可用命令

| 子库 | 可选命令 |
|------|---------|
| materials | 无操作, 导入, 导入几何体, 创建资产, 应用材质到选中对象 |
| models | 无操作, 导入, 导入几何体, 创建资产 |
| textures | 无操作, 导入, 导入几何体, 导入贴图, 创建资产, 创建材质, 应用材质到选中对象, 指定贴图到材质 |
| lights | 无操作, 导入, 导入几何体, 创建资产, 应用灯光参数到选中灯光 |
| hdr | 无操作, 导入, 导入几何体, 创建资产, 创建环境光, 指定贴图 |
| scenes | 无操作, 导入, 导入几何体, 创建资产 |
| ani | 无操作, 导入, 导入几何体, 创建资产 |
| 自定义库 | 无操作, 导入, 导入几何体, 创建资产 |

## JSON 数据结构

新建 `Assets/preset/double_click_preset.json`：

```json
{
    "_comment": "双击缩略图命令预设 — 按子库(asset_type)配置双击时执行的命令",
    "materials": "import",
    "models": "none",
    "textures": "create_material",
    "lights": "apply_light",
    "hdr": "create_dome_light",
    "scenes": "none",
    "ani": "none"
}
```

顶层键为子库 ID，值为命令 key 或 `"none"`（表示无操作）。

## 修改文件清单

### 1. `settings_dialog.py`

- 在 `_create_context_menu_tab()` 中，右侧下方新增 QButtonGroup + QRadioButton 组
- 定义 `_DOUBLE_CLICK_ITEMS` 字典，按子库类型映射可用的命令列表
- 新增 `_load_double_click_preset()` / `_save_double_click_preset()` 方法
- 修改 `_on_ctx_type_changed()`，切换子库时同时加载双击命令配置
- 修改保存逻辑，同时保存双击命令配置到独立文件
- 定义常量 `_DOUBLE_CLICK_PRESET_PATH`

### 2. `thumbnail_view.py`

- 新增模块级函数 `_load_double_click_preset()` 加载配置
- 修改图标视图的 `_attach_card_events()` 中的 `mouse_double` 事件，根据配置执行对应命令
- 修改列表视图的 `_on_table_double_clicked()`，同样根据配置执行命令
- 可能需要根据双击命令类型发射不同信号（`assetImportRequested`, `createAssetRequested` 等）

### 3. 新建 `double_click_preset.json`

- 初始值全部为 `"none"`

## 双击命令执行逻辑

双击时根据配置的 key，调用对应的信号/方法：

| 命令 key | 执行的逻辑 |
|----------|-----------|
| `none` | 无操作 |
| `import` | 触发 `assetImportRequested` 信号 |
| `import_geometry` | 触发 `variantGeometryImportRequested` 信号 |
| `import_texture` | 触发对应纹理导入逻辑 |
| `create_asset` | 触发 `createAssetRequested` 信号 |
| `create_material` | 触发材质创建逻辑 |
| `apply_material` | 触发 `materialApplied` 信号 |
| `assign_texture` | 触发贴图指定逻辑 |
| `apply_light` | 触发灯光应用逻辑 |
| `create_dome_light` | 触发环境光创建逻辑 |
