材质转换工具 — 使用帮助

本工具用于在 Maya 中进行材质类型之间的批量转换，支持自定义映射关系，可处理大批量场景中的材质替换工作（如将所有 lambert 材质转换为 aiStandardSurface）。

1. 工具概述

工具可以帮你做这些事：

  • 批量转换 — 一次性转换场景中所有匹配的材质，或仅转换选中的材质
  • 类型映射 — 定义源材质类型到目标材质类型的对应关系，源/目标类型支持下拉选择
  • 属性映射 — 通过 .mmap 映射文件控制属性传递
  • openPBR 中转 — 没有直接映射文件时，自动通过 openPBR 中间格式完成两步转换
  • 失败处理 — 转换失败的材质自动跳过并生成报告，可一键在 Maya 中选中
  • 默认材质兜底 — 可选：无映射文件时创建目标类型的基础材质替换
  • 预设保存 — 常用映射配置可保存为 .mlist 文件复用

2. 使用步骤

2.1 配置材质类型映射

  1. 在"材质类型映射配置"表格中，添加源材质类型和目标材质类型的映射关系
  2. 源/目标单元格是下拉框：选项自动来自映射文件夹中的 .mmap 文件（即可以进行转换的类型），也可以直接输入自定义类型
  3. 也可以点击"加载源"/"加载目标"按钮从选择的材质节点载入类型
  4. 当只有一行且源为空时，会将所有材质转换为该目标类型
  5. 可以点击"保存预设"将当前配置保存为 .mlist 文件

2.2 选择映射文件

  1. 映射文件区域位于窗口顶部：点击"浏览..."按钮选择包含映射 .mmap 文件的文件夹
  2. 区域下方显示当前映射文件夹的目录路径，点击"打开文件夹"可快速在资源管理器中打开
  3. 工具会自动加载该文件夹中的所有 .mmap 文件，并根据"源材质类型"和"目标材质类型"自动匹配
提示：.mmap 映射文件可以由"材质节点属性映射工具"创建和管理。

2.3 执行转换

  1. 配置好映射关系后，点击"转换选择"按钮 — 仅转换选中的材质
  2. 或点击"转换全部"按钮 — 转换场景中所有符合映射配置的材质
  3. 转换时会自动查找转换路径：优先使用直接映射文件（A→B），找不到时自动尝试 openPBR 中转（A→openPBR→B）
  4. 转换过程中会在底部状态栏显示进度
  5. 完成后弹窗显示成功/失败的材质数量；若有失败材质，可在弹窗中一键选中定位
注意：建议在转换前保存场景文件。批量操作前备份是个好习惯。

2.4 转换选项

选项说明
复制纹理连接转换时将源材质的纹理（贴图文件）连接复制到目标材质（默认开启）
保留原始材质转换完成后保留源材质节点不删除（默认不勾选，勾选后便于回退）
自动应用到选择对象转换后将新材质自动赋予当前选中的对象（默认开启）
无映射→默认材质找不到对应映射文件时，创建目标类型的基础材质替换源材质（默认不勾选；不勾选时此类材质计入转换失败列表）

3. 界面说明

3.1 映射文件区域（顶部）

位于窗口最上方，包含两行：

  • 第一行：映射文件路径输入框（只读）+ "浏览..."按钮 + 状态标签
  • 第二行：映射文件夹目录路径文本 + "打开文件夹"按钮

3.2 映射配置表格

配置"源材质类型 → 目标材质类型"的对应关系：

  • 源：要转换的材质类型（如 lambert、phong、blinn），下拉框选择或输入
  • 目标：转换后的材质类型（如 aiStandardSurface、redshiftStandardMaterial），下拉框选择或输入

表格下方按钮行：

按钮功能说明
加载源将当前选中的 Maya 材质节点类型载入到"源"单元格
加载目标将当前选中的 Maya 材质节点类型载入到"目标"单元格
添加行在映射配置表格中新增一行
删除选中行删除映射配置表格中选中的行
清空全部清空映射配置表格中的所有行
保存预设将当前映射配置保存为 .mlist 文件
加载预设从 .mlist 文件恢复映射配置
特殊用法：当只有一行且"源"留空时，会将所有材质都转换为该"目标"类型。这在"全部转换为统一类型"的场景下非常有用。

3.3 底部按钮与状态栏

按钮功能说明
转换选择仅转换当前在 Maya 中选中的材质
转换全部转换场景中所有匹配映射配置的材质
关闭关闭工具窗口

窗口底部状态栏显示当前操作进度与结果信息。

4. openPBR 中转转换

不同渲染器之间的材质转换依赖 .mmap 映射文件。为避免"每种 A→B 组合都做一份映射文件"导致的文件数量膨胀，工具引入了 openPBR 中间格式：

  • 只需要准备 A→openPBR、openPBR→A、B→openPBR、openPBR→B 等映射文件
  • 当用户想要 A→B 而没有直接映射文件时，工具自动执行 A→openPBR 再 openPBR→B 两步转换
  • 中转过程产生的中间 openPBR 材质会自动清理，最终只保留目标材质
示例：有 lambert→openPBRSurface.mmap 和 openPBRSurface→VRayMtl.mmap，但没有 lambert→VRayMtl.mmap 时，工具会自动完成 lambert→openPBR→VRayMtl。

5. 转换失败处理

转换过程中不会因单个材质失败而中断：

  • 找不到映射文件或转换出错的材质会跳过，继续转换其余材质
  • 转换完成后弹窗列出失败材质列表及失败原因
  • 弹窗中提供"选择失败材质"按钮，可在 Maya 视口中一键选中所有失败材质，便于逐个检查修复

如果勾选了转换选项中的"无映射→默认材质"，找不到映射文件的材质不会进入失败列表，而是直接创建目标类型的基础材质替换源材质（仅保证类型正确，不复制属性）。

6. 预设管理

预设文件位置

预设文件存放在工具的 preset/ 目录下，扩展名为 .mlist。

预设文件结构

预设文件是 JSON 格式，包含映射关系列表：

{
  "version": "1.0",
  "mappings": [
    {"source": "lambert", "target": "aiStandardSurface"},
    {"source": "phong", "target": "redshiftStandardMaterial"},
    {"source": "", "target": "aiStandardSurface"}
  ]
}

预设 vs 映射文件

类型扩展名作用
预设（Preset）.mlist保存"源类型 → 目标类型"的对应关系
映射文件（Map）.mmap保存"源属性 → 目标属性"的详细映射规则
配合使用：预设定义"什么类型转什么类型"，映射文件定义"类型之间属性怎么传"。两者配合完成完整转换流程。

7. 使用技巧

  1. 先小范围测试：先用"转换选择"测试一两个材质，确认效果后再用"转换全部"
  2. 统一目标类型：如需将所有材质统一为 PBR 材质，使用"源留空 + 单行"的配置
  3. 善用 openPBR 中转：为常用渲染器各准备一份"→openPBR"和"openPBR→"映射，即可覆盖任意渲染器之间的转换
  4. 复用映射：相同材质类型转换一次后，预设和映射文件可永久复用
  5. 分层处理：复杂场景可分批转换（如先转 lambert，再转 phong）
  6. 检查失败材质：转换完成后如弹窗提示失败，用"选择失败材质"按钮定位后逐个修复
  7. 团队共享：将 preset/ 目录与映射文件目录加入共享路径，统一团队转换标准

8. 常见问题

Q: 转换后材质效果不对？

A: 大多数情况是 .mmap 映射文件不完整。可以使用"材质节点属性映射工具"创建更详细的映射规则。

Q: 找不到对应的 .mmap 文件？

A: 映射文件夹中没有匹配的 .mmap 文件。可以：
1. 在映射文件夹中创建匹配的映射文件（也可准备 openPBR 中转映射）
2. 使用"材质节点属性映射工具"创建新的映射文件
3. 或勾选"无映射→默认材质"选项，让工具创建默认目标材质

Q: 转换失败了？

A: 检查以下几点：
1. 目标渲染器是否已加载（Arnold / Redshift 插件）
2. 源节点类型名称是否拼写正确（区分大小写）
3. 场景中是否有同名材质导致冲突
4. 用转换完成后的"选择失败材质"按钮定位具体问题材质

Q: 转换很慢？

A: 大场景批量转换会逐个节点处理，属正常现象。可以观察状态栏进度。如卡死请检查是否有复杂节点网络。

Q: 能撤销转换吗？

A: 勾选"保留原始材质"选项后源材质节点不会删除，可手动删除目标材质并重新使用源材质。如需彻底转换请在转换前保存场景。

Q: 支持哪些渲染器？

A: 理论上支持所有 Maya 已加载的渲染器。常用支持：
• Arnold (aiStandardSurface)
• Redshift (redshiftStandardMaterial)
• V-Ray (VRayMtl)
• RenderMan (PxrSurface)
• Stingray (StingrayStandardMaterial)
渲染器之间没有直接映射时，通过 openPBR 中间格式也能完成转换。
