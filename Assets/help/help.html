🐿 Squirrel Asset Manager 使用帮助

1. 右键菜单操作

📥 导入

将资产的几何体文件导入到 Maya 当前场景（节点合并到场景中，不保留引用关系）。
支持的格式：ma mb fbx abc usd obj glb

🔗 添加引用 新功能

将资产的几何体文件以 Maya Reference 方式引用到当前场景。与导入的区别：

导入添加引用
方式cmds.file(i=True)cmds.file(reference=True)
场景关系节点合并到场景创建引用节点，源文件独立
命名空间无自动创建（资产名）
引用编辑器不可见可在 Reference Editor 中管理
支持的格式全部ma mb fbx abc usd obj
使用说明：
• 右键资产卡片 → 添加引用
• 若 .zasset 中包含多种格式，可选择目标格式
• 引用路径遵循 依赖导入策略（设置→常规→依赖文件导入策略）：
   — 当前资产目录：引用直指 .zasset 内文件（无需复制）
   — 复制到工程目录：文件复制到 references/squirrel_asset/ 目录
• 嵌套引用（reference 内部关联的其他引用）自动重定向

2. 资产导出

选中 Maya 物体 → 导出为 .zasset 格式。支持：

  • 几何体：ma mb fbx abc usd obj
  • 材质预设：.zmetal（合并模式可合并所有关联材质）
  • 灯光预设：.zlight
  • 贴图自动收集：支持 file 节点、RedshiftDomeLight HDR、序列帧、UDIM
  • 关联文件自动收集：Alembic 缓存、GPU Cache、VDB、代理文件、引用文件
  • 缩略图自动生成

3. 资产导入

双击或右键导入资产到 Maya。支持：

  • 几何体导入 / 变体导入（版本 + LOD）
  • 材质导入（.zmetal → 重建 shading 网络）
  • 贴图导入（单张贴图 / 共享UV批量导入）
  • 灯光导入（支持 Arnold / V-Ray / Redshift / Maya 原生）
  • HDR 环境光创建
  • 贴图路径自动重定向（copy_to_project / asset_directory / source_directory）

4. 分类专属功能

子库专属右键功能
材质应用材质到选中对象 / 创建材质
贴图创建材质 / 导入贴图 / 指定贴图到材质
灯光应用灯光参数到选中灯光 / 以指定渲染器导入
HDR创建环境光（Dome Light）/ 指定 HDR 到选中灯光
模型 / 场景 / 动画导入几何体 / 变体导入

5. 设置说明

点击工具栏 ⚙ 按钮打开设置面板，包含：

  • 常规：字体大小、默认视图、名称冲突处理、贴图导入策略、依赖文件导入策略
  • 导出默认值：按资产类型配置导出的几何体格式
  • 右键菜单：自定义各子库右键菜单项（含"添加引用"开关）
  • 支持格式 / 贴图后缀 / 常用标签 / 子库与分类

依赖文件导入策略

控制引用和关联文件的路径解析方式：

策略效果
asset_directory直接指向 .zasset 目录（不复制文件）
copy_to_project复制到工程 cache/ / references/ 目录
source_directory保持原始路径（按 .zasset 打包时的原路径）

6. 快捷键

  • 双击资产：执行双击命令（可在设置中配置，默认导入）
  • Ctrl+F：聚焦搜索框
  • Ctrl+A：全选
  • Delete：删除选中资产
