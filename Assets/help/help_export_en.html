Export Assets — Interface Guide

Interface Overview

The export dialog (780×760) is split into two columns: the left controls the flow, the right configures the content.

Left Panel — Export Controls

Export Asset (blue button)
Click to start the export. The dialog is non-modal, so you can operate other UI while exporting.
Export Mode (three radio buttons)
OptionDescription
Fully AutomaticWith multiple objects, each is exported independently. After the first framing it is reused automatically; no manual screenshots are needed throughout
Semi-automaticEach object is exported independently, and a screenshot UI pops up for each to adjust the camera manually
Single AssetNo matter how many objects are selected, all are merged into one asset. Unselected objects are not hidden automatically; isolate the view manually

Right Panel — Export Content

Collect Associated Files

Collect caches/proxies/references loaded in the scene — when checked, automatically scans the caches (Alembic/gpuCache/nCache), proxies (Arnold/V-Ray/Redshift/USD) and Maya references associated with the selected objects, and copies them to the associated/ directory.
When checked, V-Ray .vrmesh/.vrscene, Redshift .rs and USD .usd proxy files do not need to be re-exported — they are copied directly from disk, which is extremely fast.
Textures textures/ — checked by default; collects the texture files associated with the materials into the textures/ directory. Uncheck it to skip packaging textures, suitable for pure-geometry exports or when textures are managed externally.
Export materials only (skip geometry/proxies) — when checked, only material nodes and textures are exported; geometry formats and proxy formats are not exported.
Asset Name — input field, defaults to the selected object's name. The asset is stored as {name}.zasset in the category folder.
Display Name — optional. A friendly display name shown in the UI.
Tags — comma-separated (e.g. metal, highlights). Used for searching and filtering.
The name, display name, and tags also update the name and tags of any existing asset of the same name imported into this category.

Material / Node Formats

Material preset .zmetal — when checked, exports the Maya material node data. With multiple materials you can choose "Merge" or export them separately.
Light preset .zlight — when checked, exports renderer-independent light data (color/intensity/exposure/color temperature + upstream texture/IES/HDR node networks). On import you can choose Arnold / V-Ray / Redshift / Maya native, and the corresponding light nodes are created automatically. The same .zlight can be used across renderers.
Material mapping .mcm — records the object's vertex/face/edge counts for automatic model matching on import. Only available when .zmetal is checked.

Animation Export

Determines the frame range for abc/usd/ass/rs/vrmesh:

  • Current Frame — still-frame asset
  • Timeline — full animation (playback range). Also triggers MP4 animated thumbnail generation
  • Keyframes — the object's keyframe range
Timeline + Render: rendering is executed uniformly after the assets are exported. Maya may become temporarily unresponsive — this is normal rendering, please wait.

Full Export Flow

  1. Select the objects to export in the Maya scene
  2. Click the Export button on the toolbar
  3. Choose the Export Mode and Thumbnail Source
  4. Check "Collect Associated Files" to automatically package caches/proxies/references in the scene
  5. Configure the export content on the right (geometry/cache/proxy formats)
  6. For animation export, choose "Timeline" or "Keyframes"
  7. Enter the asset name and tags
  8. Click "Export Asset"
  9. Take the screenshot as prompted
  10. Export completes, and the asset appears in the grid
Thumbnail generation timing: Screen capture generates the thumbnail immediately in the screenshot UI; playblast/render are generated uniformly after all assets are exported, without interrupting geometry export.
Single Asset export: In single-asset mode the unselected objects are not hidden automatically. To isolate the view, do it manually (press Shift+I to isolate), then restore after taking the screenshot.

The following formats automatically recognize frame sequences and copy all files frame by frame:

LOD & Version Management

Concept

LOD (level of detail) and Version are the two core variant dimensions, and LODs belong to a version:

  • Version — content iterations of the same asset (v1=base version → v2=damaged version); materials and textures are shared across all versions
  • LOD — geometric detail changes within the same version (lod0=high detail → lod1=medium detail → lod2=low detail)

Example directory structure:

SciFi_Crate.zasset/
├── meta.json           # metadata (shared)
├── node.zmetal          # material nodes (shared)
├── textures/            # textures (shared by all variants)
└── variants/            # variants directory
    ├── v1/              # version 1 — base version
    │   ├── lod0/        #   high detail (15,420 faces)
    │   ├── lod1/        #   medium detail (5,020 faces)
    │   └── lod2/        #   low detail (1,200 faces)
    └── v2/              # version 2 — optimized version
        ├── lod0/        #   high detail (16,800 faces)
        └── lod1/        #   medium detail (5,500 faces)

Append an LOD — add a detail level to an existing version

  1. Select the decimated geometry in the Maya viewport (e.g. the lod1 model)
  2. Right-click the asset thumbnail → "Update Asset"
  3. In the export dialog, check a geometry format (ma / fbx, etc.)
  4. Click "Export Asset"
  5. In the pop-up dialog, choose "Append as LOD"
  6. The system automatically detects the face count and writes it to variants/{version}/lod{N}/
Note: Before appending an LOD, make sure a geometry format (ma/fbx/obj, etc.) is checked in the "Update Asset" dialog. With multiple versions, after clicking "Append as LOD" a version selector appears where you can choose which version to append the LOD to.

Create a New Version — use when the model content changes

  1. Modify the model (add damage/change UVs, etc.)
  2. Select the modified model in the Maya viewport
  3. Right-click the asset → "Update Asset"
  4. Check a geometry format → click "Export Asset"
  5. Choose "Create New Version"
  6. variants/v2/lod0/ is created automatically; you can continue appending lod1 to v2 later
Versions and materials: When creating a new version, if the .zmetal material format is checked, the system exports the materials and textures together to variants/{version}/node.zmetal and variants/{version}/textures/, giving the version independent materials. If unchecked, all versions share the root-level materials.

Version-Independent Materials

When different versions need different materials/textures (e.g. v2 adds a damaged texture):

  1. Set up the new version's material and textures in Maya
  2. Select the modified model
  3. Right-click the asset → "Update Asset"
  4. Check the .zmetal material format + a geometry format
  5. Click Export → choose "Create New Version"
  6. Materials and textures are written to variants/v2/ automatically

Directory structure:

SciFi_Crate.zasset/
├── node.zmetal          # v1 material (root-level, compatible with legacy assets)
├── textures/            # v1 textures
└── variants/
    ├── v1/
    │   └── lod0/node.ma  # geometry only, uses the root-level material
    └── v2/
        ├── node.zmetal   # v2 independent material
        ├── textures/     # v2 independent textures
        └── lod0/node.ma

On import, versions with independent materials show an "Import {version number} version materials" entry under the "Switch Version" submenu of the right-click menu; clicking it imports that version's independent materials. Versions without independent materials fall back to the root-level materials.

Delete a Version / LOD

The "Import Geometry" submenu of the right-click menu provides deletion functions at the bottom:

Menu LocationActionEffect
LOD Level → 🗑 Delete {level}Deletes a single LODRemoves the variants/{version}/{lodN}/ directory
Switch Version → 🗑 Delete {version number}Deletes an entire versionRemoves the variants/{version}/ directory and all its LODs and materials
Deletion cannot be undone! A confirmation dialog appears before deletion. Deleting a version also removes all LODs and independent material files under that version. When all versions are deleted, the variant system is automatically disabled.

Import Variant Geometry

Right-clicking an asset that has variants additionally shows "📦 Import Geometry" in the menu:

Menu ItemDescription
LOD LevelLists all LODs of the current version (including face counts); click to import directly
Switch VersionLists all available versions; after selecting, imports with that version's default LOD. Versions with independent materials additionally show "Import Version Materials"
Choose Version and LOD...Opens a full selection dialog where you can choose both the version and the LOD level

Menu rules:

  • Only 1 version → "Switch Version" is not shown; that version is used directly
  • Only 1 LOD → the "LOD Level" submenu is not shown; it imports directly
  • No variants → "Import Geometry" is not shown; original behavior is retained
Before importing: Importing geometry loads the model into the current Maya scene. To replace an existing model, delete the old model manually first.

Replace Asset vs. Append Variant

When updating an asset there are three options:

Common Errors

❌ No geometry: Make sure at least one format is checked

❌ Timeline + Render freezes: This is normal; wait for it to finish or switch to playblast

❌ Missing format: Confirm the corresponding checkbox was checked when exporting

❌ "Update Asset" does not show the LOD/version dialog: Check whether a geometry format (ma/fbx/obj, etc.) is checked; the dialog only appears when geometry is being exported

❌ Nothing happens after clicking LOD: Make sure you have selected the geometry objects to export in the Maya viewport before clicking OK

❌ Reference files are baked into .ma: This is normal. Maya exports with the preserveReferences flag to keep the reference relationship; the referenced source files are backed up in associated/references/

❌ Objects disappear in single-asset mode: Clicking "Single Asset" does not hide objects automatically. To isolate the view, operate the view manually
