Library Management

Manage the locations and names of multiple asset libraries. Supports add, delete, and set-as-default operations.

  1. + Add Library — choose an asset library folder on disk and enter a display name
  2. - Delete Selected — removes it from the list (does not delete on-disk files). At least one library must remain
  3. ☆ Set as Default — the library marked [Default] is loaded automatically when the plugin starts
Tip: The core directory structure (materials/, models/, etc.) is created automatically in a newly created empty folder the first time you switch to that library.

Export Defaults

Set the default checked state of export formats separately by asset type (material/model/light/texture/scene/HDR/dynamic).

GroupIncluded Formats
Material FormatsMaterial nodes (.zmetal), merged materials, material mapping (.mcm)
Geometry FormatsMaya ASCII (.ma), Maya Binary (.mb), FBX (.fbx), OBJ (.obj), USD (.usd)
Cache & ProxyAlembic (.abc), Arnold (.ass), V-Ray (.vrscene), Redshift (.rs), V-Ray proxy (.vrmesh)
Effect: When the export dialog is first opened, the default value of each format checkbox is read from these presets based on the current asset type. For example, model-type assets default to FBX checked, and material-type assets leave geometry unchecked by default.

Supported Formats

Defines which file extensions are treated as importable asset files. One extension per line (without the dot).

The data is stored in the asset_file_extensions field of config.json.

Note: After modifying, click "Apply" for the changes to take effect. Incorrect configuration may cause asset import to malfunction.

Texture Suffixes

Configure the filename matching rules for PBR texture types.

Configuration ItemDescription
Left Type ListPBR texture types (albedo / normal / roughness / metallic / ao, etc.)
Right Alias ListThe filename keywords corresponding to that type; the engine uses these keywords to identify the texture type

For example: the aliases of the normal type include _normal, _nrm, _n, so a file named crate_n.png is recognized as a normal map.

Tip: Clicking "Restore Defaults" resets all aliases to factory settings. The data comes from Assets/preset/pbr_mapping.json.

Common Tags

Manage the list of common tags separately by sub-library type (material/model/light/texture/scene/HDR).

  • Select a sub-library type on the left → edit its tags on the right (one per line)
  • Tags are presented as quick buttons in the export dialog; click to add
  • The data is stored in the common_tags field of config.json

Sub-libraries & Categories

Manage a sub-library's ID, display name, and default category list. Supports adding custom sub-libraries, deleting custom sub-libraries, and syncing categories from the actual folders.

FieldDescription
Sub-library IDThe unique identifier of the sub-library (e.g. materials), which must not duplicate other sub-libraries
Display NameThe name shown in the UI (e.g. "Materials")
Default Category ListThe category folders auto-generated the first time this sub-library is created, in the format id name

Adding a Sub-library

Right-click an empty area in the left sub-library list and choose "Add Sub-library". The new sub-library's ID format is custom_N and its display name is "Custom N".

Deleting a Sub-library

Right-click a custom sub-library and choose "Delete Sub-library". Core sub-libraries (materials, models, lights, textures, scenes, HDR, dynamic) cannot be deleted.

Syncing Categories

Click the "Read Current Category Folders" button above the right editing area to sync the actual folder structure of the current asset library to the settings. This overwrites the existing default category list configuration.

Editing Categories

In the category tree, right-click a category and choose "Edit" to modify its readable name and type. The type dropdown lists all sub-library types, ensuring the personalized context menu is recognized correctly.

Note: The seven core sub-libraries (materials / models / lights / textures / scenes / hdr / ani) cannot be deleted; changing their IDs may make existing data unusable.
