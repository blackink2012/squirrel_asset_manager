Material Node Attribute Mapper — Help

This tool is used to define attribute mapping relationships between Maya material nodes, with support for default values and transform functions. It is mainly used for converting attributes between material types of different renderers (e.g., lambert → aiStandardSurface).

1. Overview

This tool can help you:

  • Automatically load node attributes — after setting the source/target node types, the drop-down list is automatically populated with all readable and writable attributes of that type
  • Batch mapping — configure multiple attribute mappings at once through the table
  • Value transforms — supports simple transform functions (such as 1-x to invert roughness)
  • Save/load presets — mapping configurations can be saved as .mmap files for quick recovery next time
  • Reverse mapping — one-click swap of source and target roles
  • Attribute browser — a separate window to view all attributes and their current values of nodes in the scene

2. Quick Start

Typical Workflow

  1. Set source node type: select a source material node in Maya, then click the source "Browse" button; you can also type the node type directly into the text box (e.g., lambert)
  2. Set target node type: set the target type the same way (e.g., aiStandardSurface)
  3. Add mapping rows: click the "Add Row" button; each row's drop-down is automatically populated with the corresponding type's attributes
  4. Configure the mapping: select the source and target attributes in each row, filling in the transform function and default value as needed
  5. Save the preset: click "Save Preset" to store the mapping configuration as a .mmap file
Tip: The "Add Row" button also works when no node type is set, but the drop-down lists will be empty. You can manually enter attribute names later.

4. Context Menu

The tool provides two right-click menus:

  • Table cell right-click: right-click on the source or target attribute column to quickly "Clear Source Attributes" or "Clear Target Attributes"
  • Whole table right-click: right-click on an empty area to perform "Reverse Mapping", "Clear Table", "Load Sample Data", "Load Preset", etc.

5. Transform Functions

The "Transform Function" column is used to perform simple mathematical transforms when passing attribute values, for example:

ScenarioTransform FunctionDescription
Invert roughness1-xUsed when Maya's roughness follows a 1-roughness relationship
Normalizex/255Maps from 0-255 to 0-1
Denormalizex*255Maps from 0-1 to 0-255
Gamma correctionx**2.2Linear → sRGB conversion
Note: Transform functions use Python expression syntax; x represents the current attribute value. Only simple mathematical operations are supported; function calls or custom functions are not allowed.
Default value: the default value used when the target attribute has no value. For example 0.5, (0,0,0), "", etc.

6. Preset Management

Preset File Location

Preset files are stored in the tool's preset/ directory with the .mmap extension. You can quickly locate them using the "Open Folder" button at the bottom of the interface.

Preset File Naming

It is recommended to use the 源类型_目标类型.mmap naming format, for example:

  • lambert_aiStandardSurface.mmap
  • phong_redshiftStandardMaterial.mmap
  • standardSurface_arnold.mmap

Preset File Structure

The preset file is in JSON format and contains:

{
  "source_type": "lambert",
  "target_type": "aiStandardSurface",
  "mappings": [
    {"source": "color", "target": "baseColor", "transform": "", "default": ""},
    {"source": "transparency", "target": "opacity", "transform": "", "default": "1.0"},
    ...
  ]
}

8. Usage Tips

  1. Quickly populate attributes: set the source/target node types first, then click "Add Row"; the drop-down automatically shows all attributes of that type
  2. Batch multi-delete: check the checkboxes in front of multiple rows, then click "Remove Selected Rows" to delete several rows at once
  3. Reuse via reverse mapping: after completing an A → B mapping, click "Reverse Mapping" to obtain the B → A configuration (note that transform functions need to be adjusted manually)
  4. Complex value transforms: for complex logic (conditionals, string processing, etc.), use Maya's built-in connection expressions or scripts
  5. Preset version control: preset files are plain JSON and can be version-controlled with Git/SVN
  6. Team collaboration: add the preset/ directory to a shared path so team members can use the same set of mappings

9. FAQ

Q: Why is the drop-down list empty?

A: You need to set the source/target node types first (click the "Browse" button or type manually). The node type determines the contents of the drop-down list.

Q: What is the attribute browser for?

A: It is used to quickly view all attributes and their current values of the selected node in the scene. You can refer to the actual values when writing in the "Transform Function" column. You can also drag attributes from the browser into the table.

Q: What syntax do transform functions support?

A: Python mathematical expressions are supported; x represents the current attribute value. For example 1-x, x*2, x**0.5.

Q: Can preset files be used across tools?

A: .mmap presets are a tool-specific format and cannot be used directly by other tools. However, their JSON structure is simple and a script can be written to convert them.

Q: What happens to transform functions after reverse mapping?

A: Transform functions are kept unchanged and are not automatically inverted. If the original function was 1-x, you may need to change it to x or an inverse function when reversing.
