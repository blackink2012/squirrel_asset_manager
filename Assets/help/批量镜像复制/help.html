批量镜像复制工具

本工具可将源文件夹中指定格式的文件按完整的目录层级结构镜像复制到目标文件夹，适用于资产归档、文件分发和目录结构备份等场景。

1. 工具概述

批量镜像复制工具可以：

  • 按文件扩展名过滤并批量复制文件
  • 保持源文件夹的完整目录层级结构
  • 跳过目标位置已存在的文件，避免重复复制
  • 支持预览模式，先行查看将要复制的文件列表
  • 实时显示复制进度和操作日志
  • 后台线程运行，界面不卡顿
  • 使用 shutil.copy2 保留文件元数据（修改时间等）

2. 核心功能

功能说明
镜像复制将源文件夹中匹配的文件按相对路径完整复制到目标文件夹，保持目录结构不变
格式过滤按文件扩展名筛选要复制的文件，支持逗号分隔多个格式
跳过已存在目标位置已存在的文件自动跳过，不会覆盖
预览模式仅显示将要复制的文件列表，不实际执行复制操作
进度追踪实时进度条 + 详细操作日志，完成时弹出统计摘要

3. 界面说明

3.1 源文件夹

选择要从中复制文件的源文件夹。所有匹配的文件将按其在源文件夹中的相对路径进行复制。

3.2 目标文件夹

选择文件要复制到的目标文件夹。工具会在目标文件夹中自动重建源文件夹的目录结构。

注意：源文件夹和目标文件夹不能相同，否则会导致操作被拒绝。

3.3 文件格式

指定要复制的文件扩展名，多个格式用逗号分隔。扩展名不区分大小写，可带或不带前导点号。

输入内容效果
.exr, .hdr, .png, .jpg复制 EXR、HDR、PNG 和 JPEG 文件（默认值）
exr, hdr仅复制 EXR 和 HDR 文件（自动补全点号）
.tif, .tiff, .exr复制 TIFF 和 EXR 文件

3.4 预览选项

勾选「仅预览（不实际复制）」后，点击开始复制将只扫描文件并列出匹配结果，不会执行任何复制操作。

3.5 操作按钮

按钮功能
开始复制扫描源文件夹并开始镜像复制（或预览）
清除日志清空操作日志区域的内容
退出关闭工具窗口

3.6 进度与日志

  • 进度标签：显示当前处理状态（等待中 / 扫描中 / 处理中 / 完成）
  • 进度条：显示整体完成百分比
  • 操作日志：以时间戳记录每步操作，包括复制、跳过、失败等信息

4. 使用流程

标准复制流程

  1. 点击源文件夹旁的「浏览」按钮，选择要复制的源文件夹
  2. 点击目标文件夹旁的「浏览」按钮，选择目标文件夹
  3. 在文件格式输入框中指定要复制的文件扩展名（多个用逗号分隔）
  4. （可选）勾选「仅预览」先行查看匹配结果
  5. 点击「开始复制」按钮开始操作
  6. 观察进度条和操作日志，等待完成
  7. 完成时弹出统计摘要对话框

4.1 预览模式

预览模式不会实际复制任何文件，仅用于查看源文件夹中哪些文件将被匹配和复制。适用于：

  • 确认文件格式过滤器是否配置正确
  • 了解将要复制的文件总数和大小
  • 验证目录结构是否符合预期
提示：预览模式下匹配的文件数量与实际复制一致，可以准确评估操作规模。

5. 常见问题

源文件夹和目标文件夹能否相同？

不能。工具会检测源文件夹和目标文件夹是否相同，相同时会拒绝执行并提示错误。

目标文件已存在会怎样？

工具会自动跳过目标位置已存在的文件，不会进行覆盖。每条跳过记录都会在操作日志中以 [跳过] 标记显示。

复制失败怎么办？

单个文件复制失败不会中断整体流程，工具会继续处理后续文件。操作完成后会弹出统计摘要，其中列出所有失败文件及其错误原因，方便排查。

目录结构是如何保持的？

工具会计算每个文件相对于源文件夹根目录的路径，然后在目标文件夹中重建相同的相对路径。例如源文件夹中的 maps/diffuse/color.exr 会复制到 目标文件夹/maps/diffuse/color.exr。

文件元数据会保留吗？

工具使用 shutil.copy2 进行复制，会尽可能保留文件的修改时间等元数据信息。

复制过程中界面会卡顿吗？

不会。复制操作在独立的后台线程中执行，界面通过定时器（100ms 间隔）轮询进度队列进行更新，保持流畅响应。

可以复制大量文件吗？

可以。工具使用 os.walk 递归扫描源文件夹，对文件数量没有硬性限制。但处理大量文件时，扫描阶段可能需要一定时间。
